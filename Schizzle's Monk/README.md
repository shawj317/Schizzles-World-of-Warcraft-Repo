# Schizzle's Monk

World of Warcraft: Mists of Pandaria Classic (5.5.x) addon setups for Brewmaster and Windwalker Monks, by **Jon Shaw (Schizzle)**. Each addon has its own folder under `AddOns/`:

| Folder | What it is | Status |
|---|---|---|
| [AddOns/WeakAuras](AddOns/WeakAuras/) | **Schizzle's Monk Rotation WeakAura**: a rotation helper for Brewmaster (tank or DPS, with an Auto/Tank/DPS mode) and Windwalker, with Chi pips, Stagger and Shuffle bars, defensives, cooldowns, keybinds and interrupt alerts. Import string: [All-in-One Rotation.txt](AddOns/WeakAuras/All-in-One%20Rotation.txt) | Available (v5) |
| [AddOns/Plater](AddOns/Plater/) | **Schizzle's Monk Plater Profile**: one flat dark nameplate profile for both specs, plus five mods: stance-aware threat colours (Sturdy Ox = tank), target and focus highlight, Spear Hand Strike ready glow, an Execute and Touch of Death indicator, and threat %. Import strings: [Brewmaster and Windwalker Profile.txt](AddOns/Plater/Brewmaster%20and%20Windwalker%20Profile.txt), mods in [Mods/](AddOns/Plater/Mods/) | Available (v1) |
| [AddOns/Details!](AddOns/Details!/) | **Schizzle's Monk Details! Profile**: a two-window Brewmaster damage meter (Damage Done plus Damage Taken with tank avoidance recording), plus an optional Tank Mitigation custom display. Import strings: [Brewmaster Profile.txt](AddOns/Details!/Brewmaster%20Profile.txt), [Tank Mitigation Display.txt](AddOns/Details!/Tank%20Mitigation%20Display.txt) | Available (v2, Brewmaster only) |

Each folder's README has the import steps. There are no Monk Pawn scales yet.

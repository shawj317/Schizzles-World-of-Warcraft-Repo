# WoW Forever

Addon profiles and import strings for World of Warcraft: Forever, by Jon Shaw (Schizzle).

Nothing is here yet. Schizzle's class kits (WeakAuras, Plater, Details!, Pawn, BetterBlizzFrames) and TSM setups will be added after WoW Forever launches, adapted from the [WoW Classic - Mists of Pandaria](../WoW%20Classic%20-%20Mists%20of%20Pandaria/) versions.

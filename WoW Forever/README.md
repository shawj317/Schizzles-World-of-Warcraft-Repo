# WoW Forever

Addon profiles and import strings for World of Warcraft: Forever by **Jon Shaw (Schizzle)**.

Nothing is here yet. Schizzle's class kits (WeakAuras, Plater, Details!, Pawn, BetterBlizzFrames, BetterBlizzPlates) and TSM setups will be added after WoW Forever launches, adapted from the [WoW Classic - Mists of Pandaria](../WoW%20Classic%20-%20Mists%20of%20Pandaria/) versions.

The Warrior's [non-ElvUI interface kit](../WoW%20Classic%20-%20Mists%20of%20Pandaria/Schizzle's%20Warrior/#non-elvui-interface-kit) is built to carry over. Its helper addon and the Baganator, Auctionator, MoveAny, GTFO, BetterFishing, BetterBlizzFrames and Speedy AutoLoot setups use downloads that also run on Forever (Interface 16001). RareScanner has a separate Forever download, and its guide covers both builds. Leatrix Plus also ships one download per game version, so use its Forever file once there is one. WoW Forever behaves like the modern game in places, so Baganator, for one, uses its retail code there. Everything will be checked in game after launch.

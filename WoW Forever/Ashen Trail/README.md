# Ashen Trail — Horde 1–60 (RestedXP)

Custom **RestedXP** leveling guide for **World of Warcraft: Forever** (Ashen Trail), Horde only. By Jon Shaw (Schizzle).

## Install

1. Install [RestedXP Guides](https://www.restedxp.com/) for your Forever client.
2. Copy `AddOns/RXPGuides_CustomHordeForever` into `_forever_/Interface/AddOns/` (alongside the RestedXP addon).
3. Restart the client (or `/reload`), then open RestedXP and select group **Ashen Trail Forever (H)**.

## Route summary

Four racial starts (Durotar, Mulgore, Tirisfal, Zepheas) merge into the Barrens, then Hillsbrad / STV midgame, finishing Kalimdor and the Eastern Kingdoms through 60.

Guide chapters live in `Guides/AshenTrail.lua`.

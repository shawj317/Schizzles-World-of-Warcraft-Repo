# Schizzle's Warrior: WoW Forever launch manual

An eight-page printable manual by Jon Shaw (Schizzle) for setting up the Schizzle's Warrior kit on WoW Forever's launch day (Nov 4 2026): where the addons go, the one-click setup, a sketch of where everything sits on screen, the visual helper (Schizzle's Warrior Essentials for Musca Auras: a 1:1 sketch of its rows, the priority lanes and what each alert means), a Warrior quick reference with macros, the auction-house plan for a brand-new economy, what isn't ready yet, troubleshooting, and a tick-box test list.

| File | What it is |
|---|---|
| [Schizzles-WoW-Forever-Launch-Manual.pdf](Schizzles-WoW-Forever-Launch-Manual.pdf) | the manual (US Letter, dark pages) |
| [gen.py](gen.py) | builds it: `python3 gen.py`, then print `manual.html` to PDF with headless Chrome (the command is at the top of the file) |

The details behind each page are in the [WoW Forever](../) folder: the [helper addon](../Schizzle's%20Warrior/AddOns/SchizzlesWarriorSetup/), the [Warrior Guide](../Schizzle's%20Warrior/Warrior%20Guide.md), the [visual helper pack](../Schizzle's%20Warrior/AddOns/Musca%20Auras/), [Schizzle's TSM](../Schizzle's%20TSM/), [Addon Compatibility](../Addon%20Compatibility.md) and the [Launch Day Checklist](../Launch%20Day%20Checklist.md).

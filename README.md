# Schizzle's MoP Classic Addons

World of Warcraft: Mists of Pandaria Classic (5.5.x) addon profiles and import strings by **Schizzle (Jon Shaw)**. Built for a Brewmaster/Windwalker Monk who both tanks and DPSes.

## Projects

| Folder | What it is | Addon |
|---|---|---|
| [schizzles-monk-rotation-weakaura](schizzles-monk-rotation-weakaura/) | Monk rotation helper with tank and DPS priorities, Chi blocks, interrupt alerts | WeakAuras |
| [schizzles-plater-profile](schizzles-plater-profile/) | Nameplate profile plus 5 Lua mods (threat, focus, interrupts, execute) | Plater Nameplates |
| [schizzles-brewmaster-details-profile](schizzles-brewmaster-details-profile/) | Two linked windows: damage and tank mitigation | Details! Damage Meter |
| [schizzles-tsm](schizzles-tsm/) | Schizzle's TSM: auction house group import strings for all 15 professions (one per profession plus one all-professions string) and Battle Pets, plus realm-first Auctioning/Shopping/Crafting/Sniper/Vendoring operations | TradeSkillMaster |

Each folder has its own README with import steps and version history. The `.txt` files are the import strings; copy everything in one and paste it into that addon's Import box.

## How to use this repo (new to GitHub?)

- Click a folder above, then click a `.txt` file and use the **Copy raw file** button to copy the import string.
- To grab everything at once, click the green **Code** button, then **Download ZIP**.

# Schizzle's MoP Classic Addons

World of Warcraft: Mists of Pandaria Classic (5.5.x) addon profiles and import strings by **Jon Shaw (Schizzle)**. They're free for any player to download and import: Monk tools for Brewmaster (tank or DPS) and Windwalker, an all-in-one Warrior rotation aura and Warrior Plater profiles, and auction house groups and operations that work on any realm.

## Projects

| Folder | What it is | Addon |
|---|---|---|
| [schizzles-monk-rotation-weakaura](schizzles-monk-rotation-weakaura/) | Monk rotation helper with tank and DPS priorities, Chi blocks, interrupt alerts | WeakAuras |
| [Schizzle's Warrior](Schizzle's%20Warrior/) (rotation aura: [AddOns/WeakAuras/All-in-One Rotation.txt](Schizzle's%20Warrior/AddOns/WeakAuras/All-in-One%20Rotation.txt); nameplates: [AddOns/Plater](Schizzle's%20Warrior/AddOns/Plater/); Details! profile coming soon) | Schizzle's Warrior Rotation: all-in-one Warrior rotation helper (Arms, Fury TG/SMF, Protection) with automatic spec switching, cooldowns, rage bar, buff/debuff trackers, Prot active mitigation, interrupts. Schizzle's Warrior Plater profiles: Arms, Fury and Protection nameplate profiles that switch automatically with your spec, with tank/DPS threat colours, Pummel-ready cast bars and an Execute indicator | WeakAuras, Plater |
| [schizzles-plater-profile](schizzles-plater-profile/) | Nameplate profile plus 5 Lua mods (threat, focus, interrupts, execute) | Plater Nameplates |
| [schizzles-brewmaster-details-profile](schizzles-brewmaster-details-profile/) | Two linked windows: damage and tank mitigation | Details! Damage Meter |
| [schizzles-tsm](schizzles-tsm/) | Schizzle's TSM: auction house group import strings for all 15 professions (one per profession plus one all-professions string) and Battle Pets, plus realm-first Auctioning/Shopping/Crafting/Sniper/Vendoring operations | TradeSkillMaster |

Each folder has its own README with import steps and version history. The `.txt` files are the import strings; copy everything in one and paste it into that addon's Import box.

## How to use this repo

- Click a folder above, then click a `.txt` file and use the **Copy raw file** button to copy the import string. Each folder's README walks you through the import step by step.
- To grab everything at once, click the green **Code** button, then **Download ZIP**.

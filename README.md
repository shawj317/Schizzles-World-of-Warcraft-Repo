# Schizzle's World of Warcraft Repo

World of Warcraft: Mists of Pandaria Classic (5.5.x) addon profiles and import strings by **Jon Shaw (Schizzle)**. They're free for any player to download and import: Monk tools for Brewmaster (tank or DPS) and Windwalker (plus Pawn scales for all three Monk specs), an all-in-one Warrior rotation aura with Warrior Plater, Details! and Pawn setups, and auction house groups and operations that work on any realm.

Each class folder has a README listing its addons, and each addon folder has its own README with import steps and version history. The `.txt` files are the import strings; copy everything in one and paste it into that addon's Import box.

## How to use this repo

- Click a folder above, then click a `.txt` file and use the **Copy raw file** button to copy the import string. Each folder's README walks you through the import step by step.
- To grab everything at once, click the green **Code** button, then **Download ZIP**.

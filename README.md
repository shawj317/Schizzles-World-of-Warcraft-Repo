# Schizzle's World of Warcraft Repo

World of Warcraft addon profiles and import strings by Jon Shaw (Schizzle). What is ready today is for Mists of Pandaria Classic (5.5.x). The files are free to download and import.

The Monk folder has a rotation aura for Brewmaster (tank or DPS) and Windwalker, nameplates, a Brewmaster damage meter, and Pawn scales for all three Monk specs. The Warrior folder has an all-in-one rotation aura, plus Plater, Details!, Pawn and BetterBlizzFrames setups. The TSM folder has auction house groups for all 15 professions and for battle pets, plus operations that price from the realm you are on.

Each class folder has a README listing its addons, and each addon folder has its own README with import steps and version history. The `.txt` files are the import strings. Copy everything in one file and paste it into that addon's Import box.

## How to use this repo

1. Click a folder in the table, open its README, and follow the numbered import steps.
2. When a step tells you to copy a `.txt` file, open that file on GitHub and click the **Copy raw file** button.
3. To grab everything at once, click the green **Code** button, then **Download ZIP**.
